# .agents/

Skills e subagentes específicos do Antigravity para este projeto.
Cada skill deve ser um arquivo markdown curto e objetivo (mesmo espírito do
AGENTS.md: menos é mais, o agente carrega tudo isso no contexto).

Exemplo de estrutura:

```
.agents/
  skills/
    nome-da-skill.md
  subagents/
    nome-do-subagente.md
```
